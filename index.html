Vamos a empezar con vuestra web

Para empezar a diseñar vuestra web necesitamos conoceros un poquito y recopilar toda la información que queréis compartir con vuestros invitados.

Antes de empezar, os recomendamos tener preparadas:

  • Fotografías que queráis utilizar
  • Invitación, si ya la tenéis
  • Logo o monograma, si existe
  • Colores, tipografías o ilustraciones de vuestra boda
  • Información de ceremonia y celebración
  • Información sobre transporte, alojamiento, preboda o postboda, si aplica
  • Referencias visuales que os gusten

Importante: utilizaremos la información y los archivos que nos facilitéis en este formulario para preparar vuestra web. Intentad incluir aquí todo el material necesario para que podamos empezar a trabajar.

No os preocupéis si algún apartado no aplica: el formulario se adapta a vuestras respuestas.
